# 查看 TensorBoard

## 操作步骤

1. 进入终端，激活虚拟环境。
2. 找到日志存放路径，执行指令：

```bash
tensorboard --logdir=logs
```

> 最后的参数 `logs` 为日志文件夹的相对路径或绝对路径。

3. 打开链接，进入浏览器查看指标的变化曲线。

## 参数介绍

### 混淆矩阵基础概念

- **TP (True Positive，真正例)**：指某个类别的像素被模型正确预测为该类别。例如，在"道路"类别中，所有真实标签为"道路"且模型也预测为"道路"的像素点数量。
- **FP (False Positive，假正例)**：指模型错误地将非该类别的像素预测为该类别。例如，将"草地"或"天空"像素误判为"道路"。
- **FN (False Negative，假负例)**：指真实标签为该类别的像素被模型错误地预测为其他类别。例如，真实的"道路"像素被模型预测为"车辆"或"背景"。
- **TN (True Negative，真负例)**：指非该类别的像素被模型正确预测为非该类别。在语义分割中，由于类别众多，TN 通常不直接用于计算主要指标，但其概念是理解 FP 和 FN 的基础。

### 评价指标

- **Precision（精确率）**：衡量的是模型预测为某类别的所有像素中，真正属于该类别的比例。高精确率意味着模型的预测结果"干净"，误标区域少。

- **Recall（召回率）**：衡量的是所有真实属于某类别的像素中，被模型正确识别出来的比例。高召回率意味着模型"不漏检"，能覆盖大部分真实目标。

- **F1 分数**：是精确率和召回率的调和平均数，用于综合衡量模型在某个类别上的分割质量。

- **mIoU（平均交并比）**：

$$\text{IoU} = \frac{TP}{TP + FP + FN}$$

  IoU 的定义是预测区域与真实区域的交集除以并集，表示分割结果与真实标注的重合度。
