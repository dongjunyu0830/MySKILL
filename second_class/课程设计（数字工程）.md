## 一、土地利用类型分类与语义分割

### 1. 土地利用类型分类

土地利用类型分类是将土地按照不同的利用方式和目的进行划分，以便进行科学规划、管理和利用。分类体系主要包括以下几个方面：

- **农业用地**：主要包括耕地、园地、林地和草地。
- **建设用地**：包含商服用地、工矿仓储用地、住宅用地等。
- **交通运输用地**：包括公路、铁路、机场、港口码头等用地。
- **水域及水利设施用地**：包括河流、湖泊、水库、渠道等。
- **其他用地**：包括未利用土地、滩涂、盐碱地等。

### 2. 语义分割

**语义分割（semantic segmentation）**：就是按照"语义"给图像上目标类别中的每一点打一个标签，使得不同种类的东西在图像上被区分开来。可以理解成**像素级别的分类任务**。

- 现代语义分割在很大程度上依赖于深度学习，尤其是卷积神经网络（CNN）。
- 模型通常使用监督学习技术进行训练，需要包含详细像素级注释的大型数据集。
- 输入图像网络，输出分割图。分割图本质上是一幅图像，其中每个像素的值（通常用颜色表示）都对应于其预测的类别标签，从而直观地划分出"道路""建筑""耕地"等不同类别。

## 二、深度学习相关概念

### 1. 特征工程

- 数据和特征决定了机器学习的上限，而模型与算法则是逼近这个上限而已。特征工程做得好，算法精度也就越高。
- 传统的机器学习算法需要手工提取最有区分度的特征，如颜色、纹理、形状特征等，让算法最大程度地利用数据，从而得到更好的结果。
- 相较于传统的机器学习，深度学习的特征工程能够**自动化**。

### 2. 深度学习

- 深度学习是机器学习的一个子领域，其核心是通过多层神经网络（称为深度神经网络）从数据中自动学习复杂的特征表示。
- 可以将深度学习想象为一个流程图，从输入层开始，到输出层结束。夹在这两层之间的是"隐藏层"，负责加工处理不同级别的信息，并随着不断接收新数据而调整和适应它们的行为。
- 深层学习模型可以拥有数百个隐藏层，每个隐藏层都在数据集内发现关系和模式方面发挥作用。

### 3. 深度学习的工作原理

- 深度学习的工作原理是使用人工神经网络从数据中学习。神经网络由多层相互连接的节点组成，每个节点负责学习数据的一个特定特征。例如，在图像识别网络中，第一层节点可能会学习识别边，第二层可能会学习识别形状，第三层可能会学习识别对象。
- 在网络学习时，节点间连接的权重会随之调整，以便网络能够更好地对数据进行分类。这个过程称为**训练**，可以使用各种方法来进行训练，例如监督式学习、非监督式学习和强化学习。
- 神经网络经过训练后，可用于根据收到的新数据进行预测。

### 4. UNet 网络

UNet 采用编码器-解码器结构，配合跳跃连接，是语义分割的经典模型（详见源码与实践部分）。

## 三、基于 Tkinter 的遥感解译可视化界面

### 1. Tkinter 简介

- Tkinter 是 Python 的标准 GUI（图形用户界面）库。
- 是 Python 内置的模块，无需额外安装，适合快速开发简单的桌面应用程序。
- 通常已随 Python 安装，可通过以下代码检查：

```python
import tkinter as tk      # Python 3
print(tk.TkVersion)       # 查看版本
```

### 2. Tkinter 的核心特点

- **轻量级 & 易上手**：Python 自带，无需安装第三方库，适合初学者和小型项目。
- **跨平台支持**：支持 Windows、macOS、Linux，但界面风格较老旧（可借助 ttk 优化）。
- **基本组件齐全**：提供按钮 (Button)、标签 (Label)、输入框 (Entry)、列表框 (Listbox) 等基础控件。
- **事件驱动编程**：通过 `command` 或 `bind()` 绑定事件（如按钮点击、键盘输入）。
- **简单布局管理**：支持 `pack()`、`grid()`、`place()` 三种布局方式。

## 五、数据集介绍

### 数据集 1：CCF 大数据比赛数据（BDCI2017）

- 2015 年中国南方某城市的高清遥感图像，空间分辨率为亚米级，光谱为可见光波段（R、G、B）。
- 包含两张训练图片和标签，三张测试图片；其中含 2 张带标注的大尺寸 RGB 遥感图像（尺寸范围从 3,000×3,000 到 6,000×6,000）。
- 样本为**五类**：植被（标记 1）、建筑（标记 2）、水体（标记 3）、道路（标记 4）以及其他（标记 0）。
- 可用数据 `BDCI2017-seg/CCF-training`，里面包含两张带标签的大图，建议裁剪成 256×256 的小图后合在一起送入网络，按一定比例分成训练、测试和验证集。
- 其中，耕地、林地、草地均归为植被类。影像收集的时间跨度从 4 月到 8 月，地表变化较大，部分耕地和林地处于收获或砍伐后的状态，均被划为植被类。

### 数据集 2：MiniFrance-DFC22（DFC22）

- 由 2022 年 IEEE GRSS 数据融合竞赛提供，包含 766 张像素级标注的航空图像，每张分辨率为 512×512 像素。
- 主要用于训练土地利用类型的语义分割模型，涵盖 **12 个土地覆盖类别**：城市、工业、矿山、人造、耕地、永久作物、牧场、森林、草本植被、裸地、湿地和水域。

### 数据集 3：WHDLD（Wuhan Dense Labeling Dataset）

- 由武汉大学于 2018 年发布的高分辨率遥感影像数据集，广泛应用于遥感图像的语义分割、图像检索和场景分类等深度学习任务，每张图像分辨率为 256×256 像素。
- 涵盖 **6 个土地覆盖类别**：裸土、建筑物、人行道、道路、植被、水体。
