# MySKILL

个人技能仓库，用于收集可复用的 AI skill。

## Skills

### `project-memory-bootstrap`

为仓库初始化或修复一套受治理的三层项目记忆系统，包含：

- `memory/session/`
- `memory/project/`
- `memory/long_term/`
- 与 `AGENTS.md` 的工作流接入

目录位置：

- `skills/project-memory-bootstrap/`

主要文件：

- `PROMPT_项目记忆初始化.md`：适合迁移到其他 AI 编辑器的详尽提示词
- `SKILL.md`：精简版 skill 说明
- `references/memory-pattern.md`：三层记忆模式参考
- `scripts/bootstrap_memory.py`：初始化标准 memory 骨架的脚本
- `agents/openai.yaml`：元信息配置
