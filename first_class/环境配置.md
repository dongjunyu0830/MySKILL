环境配置
一．使用conda创建虚拟环境
安装 Anaconda 或者 Miniconda
Anaconda（功能全面，包含大量预装的数据科学库，但体积较大）
Miniconda（轻量级，仅包含 Conda 和 Python，适合按需定制）

下载路径：
		https://repo.anaconda.com/miniconda/（官方）

清华源：	
miniconda：https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/?C=M&O=D

验证conda是否安装成功


PIP镜像源切换：pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple（永久设置为清华大学镜像源）
