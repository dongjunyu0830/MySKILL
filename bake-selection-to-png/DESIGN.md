# Group to PNG 说明文档

## 背景

在 Figma 里做活动页、运营页或多语言素材时，经常会遇到一种混合诉求：

- 部分复杂装饰、背景、图片、矢量和效果希望合成一张 PNG，减少开发或下游交付时被拆成大量零碎素材。
- 文字内容又希望保留为可编辑图层，方便做多语言替换、文案调整和后续维护。
- Figma 原生的 `Flatten`、手动导出、重新拖回图片等流程步骤多，而且容易出现位置偏移、圆角/背景丢失、遮挡关系变化等问题。

因此这个插件的目标是把「选中组内一部分图层，导出成 PNG，再放回原位置并删除源图层」这套手工流程自动化，同时尽量保留未选文字和其他可编辑内容。

## 解决的问题

### 1. 多语言文字保留

运营页里常见的标题、按钮文案、活动时间、权益说明等内容需要按语言替换。如果直接把整个组导出成图片，文字就无法继续编辑。

插件支持在任意层级里只勾选要打进 PNG 的图层，未勾选文字会继续留在 Figma 中。

### 2. 减少碎片素材

复杂视觉块可能由很多图片、矢量、蒙版、阴影和装饰组成。插件会把勾选的内容合成为一张 PNG，便于交付给前端、设计验收或活动配置系统。

### 3. 避免 Flatten 变形

Figma 的 Flatten 可能改变矢量结构、蒙版或效果表现。插件使用 Figma 的 PNG 导出能力，而不是把原图层扁平化成新的矢量，因此更接近原始视觉。

### 4. 保留背景、圆角、描边和裁切

实际设计里，背景色、圆角、描边经常不在被勾选的子图层上，而是在父级 Frame 或兄弟背景层上。

插件在导出时会自动寻找相关视觉上下文：

- 半选无背景的 Group 时，向上找到最近带背景、圆角、描边、效果或裁切的父级作为导出外壳。
- 如果背景是同组里的底层矩形或背景组，导出时自动带上覆盖所选内容的下层背景。
- 未勾选的背景层只参与导出，不会被删除。

### 5. 处理 Group 位置漂移

Figma 普通 Group 会根据子图层自动计算边界。删除子图层后，Group 的边界可能改变，导致新 PNG 插入后位置漂移。

插件针对不同情况做了稳定处理：

- 整个 Group 被替换时，PNG 放到最近的非 Group 父级中，避免 Group 重算边界。
- 只替换普通 Group 的局部内容时，必要时把 Group 转成固定尺寸 Frame，再放入 PNG 和保留图层，稳定坐标体系。

### 6. 更清楚的层级选择

插件 UI 使用可展开树形结构，而不是平铺列表。父子层级支持三种状态：

- 全选
- 半选
- 未选

勾选父级会同步勾选所有后代；只勾选部分子层时，父级显示半选状态。

### 7. 可视化预览

每一行图层都有预览按钮。点击后会在当前插件窗口内弹出 popover 预览，不需要滚动到底部查看。

预览支持：

- 适应窗口
- 100%
- 放大 / 缩小
- 滚动查看
- 自动 / 深色 / 浅色 / 棋盘格背景

这可以解决透明 PNG 或白色文字在白底上看不清的问题。预览背景只影响查看，不影响最终导出文件。

## 使用方式

1. 在 Figma 中选中一个 Group、Frame、Component、Component Set 或 Section。
2. 运行插件 `Group to PNG`。
3. 在树形列表里勾选要合成 PNG 的图层。
4. 如有需要，用眼睛按钮预览图层内容。
5. 选择 PNG 倍率，通常使用 `2x`。
6. 选择 PNG 放回层级：所选最底层或所选最顶层。
7. 点击 `生成并删除所选块`。

插件会生成一张 PNG 放回合适的位置，并删除被勾选的源图层。未勾选图层会保留。

## 实现方式

### 1. 读取选中根节点

插件启动后读取当前 Figma 选区。只有选中一个可包含子层的节点时才允许操作。

支持的根节点包括：

- Frame
- Group
- Component
- Component Set
- Section

插件会递归扫描根节点下所有层级，生成一棵树形数据传给 UI。

### 2. 管理级联选择状态

UI 维护一组被勾选的图层 ID。每次点击 checkbox 时，会同步处理当前节点的所有后代，并重新计算父级状态。

真实导出前，主线程会再次过滤选中节点：

- 如果父级和子级同时被选中，只保留父级，避免重复导出。
- 确认所有选中节点仍然在当前根节点内。
- 确认可导出节点有可见渲染区域。

### 3. 计算导出上下文

插件不会简单地只导出被选中的节点。它会先计算一个导出上下文：

- 如果可以直接使用 Figma 原生导出，例如只选中一个完整子组，优先直接导出该节点。
- 如果是局部选择，则寻找最低共同父级。
- 如果最低共同父级没有视觉外壳，则继续向上查找最近带 fill、stroke、effect、corner radius 或 clipsContent 的父级。
- 同时补充可能需要一起参与渲染的下层背景节点。

这样可以在保留未选文字的同时，把背景色、圆角、描边、阴影和裁切尽量一起烘焙进 PNG。

### 4. 创建临时导出 Frame

局部导出时，插件会创建一个临时 Frame 作为导出容器。

临时 Frame 的尺寸和位置来自导出内容的绝对渲染边界。插件会把相关节点复制到临时 Frame 中，并按原文档顺序排序，保证遮挡关系接近原设计。

导出完成后，临时 Frame 会被删除，不会留在用户文件中。

### 5. PNG 生成和放回

插件调用 Figma Plugin API 的 `exportAsync` 生成 PNG 字节，再通过 `figma.createImage` 创建图片填充，最后生成一个矩形节点作为 PNG 图层。

PNG 的放回位置使用绝对坐标计算：

- 根据导出 bounds 生成目标绝对 transform。
- 根据最终父级 transform 换算成 relativeTransform。
- 在 auto layout 父级中需要时设置 `layoutPositioning = ABSOLUTE`。

### 6. 删除源图层

PNG 创建成功后，插件才删除被勾选的源图层。

删除原则：

- 只删除用户勾选的节点。
- 自动参与导出的背景层、父级外壳和未选文字不会删除。
- 如果中间 Group 被删空，会自动清理空 Group。

如果导出或插入过程中报错，插件会尽量移除已创建但未完成的 PNG，避免留下半成品。

## 适用场景

- 多语言活动页素材处理
- H5 / Web 活动页视觉资产合并
- 保留可编辑文字，同时合成复杂背景和装饰
- 将 Figma 复杂图层减少为少量 PNG，便于前端或配置系统使用
- 设计交付前快速检查哪些内容应图片化、哪些内容应保留文本

## 注意事项

- 插件生成的是 Figma 内部 PNG 图层，不会自动导出到本地文件系统。
- 如果勾选的是一个完整 Group 或 Frame，它内部文字也会进入 PNG，不再可编辑。
- 如果某些效果依赖复杂 blend mode、外部实例或特殊蒙版，建议使用预览确认后再生成。
- 普通 Group 在局部替换时可能会被转换成 Frame，这是为了稳定位置和遮挡关系。
- 预览背景只用于查看透明内容，不影响最终 PNG。
