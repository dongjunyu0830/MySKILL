# Group to PNG

一个可直接导入 Figma 的小插件：选中一个组或 Frame 后，勾选其中任意层级里要烘焙成图片的图层，生成一张 PNG 放回原结构里，并删除这些被勾选的源图层。

## 安装方式

1. 打开 Figma。
2. 进入 `Plugins` -> `Development` -> `Import plugin from manifest...`。
3. 选择本目录里的 `manifest.json`。
4. 之后从 `Plugins` -> `Development` -> `Group to PNG` 运行。

插件包里需要保留这几个文件：

- `manifest.json`
- `code.js`
- `ui.html`

## 使用方式

1. 选中一个组或 Frame。
2. 运行插件。
3. 在列表中勾选要打进 PNG 的任意层级图层。
4. 不确定内容时，点击眼睛按钮预览。
5. 选择 PNG 倍率和 PNG 放回的层级位置。
6. 点击 `生成并删除所选块`。
7. 插件会生成 PNG 放回原位置，并删除被勾选的源图层；未勾选内容会保留。

## 适合多语言的用法

- 默认会勾选可见的非文字叶子图层，文字层和容器层会默认保留。
- 被勾选的子层会被合成为一张 PNG，并从原组删除。
- 未勾选的子层不会被移动或删除，适合保留多语言文字继续编辑。
- 多个被勾选的子层会复制到临时导出容器里生成 PNG，不会把原层级拿出来重新分组。
- 如果同时勾选父层和它的子层，子层会被父层包含，导出时自动只按父层处理一次。
- 图层列表是可展开/收起的树形结构，不是平铺列表。
- 勾选父级会同步勾选它下面所有层级；子级只选了一部分时，父级会显示半选状态。
- 每一行右侧有预览按钮，点击后会在该行旁边弹出 popover 预览，并把 Figma 视口定位到它附近；预览支持适应、100%、放大、缩小、滚动查看，以及自动/深色/浅色/棋盘格背景切换。
- 导出时会复制最低共同父级作为临时外壳再裁剪未选内容，尽量保留父级 Frame 的背景、圆角、描边和裁切效果。
- 如果背景/圆角是同组里的底层矩形或背景组，插件会在导出时自动带上包住所选块的下层背景，但不会删除这些未勾选背景层。
- 如果半选的是没有背景的 Group，插件会向上找到最近的 Frame/节点视觉外壳来导出，例如父级的背景色、圆角、描边和裁切；实际删除仍只删除勾选的源图层。
- 如果只勾选一个子组，或勾选了某个父级下全部可见直接子层，插件会优先使用 Figma 原生导出这个子组/父级本身，减少位置偏移和文字渲染差异。
- 当整组被替换时，生成的 PNG 会放到最近的非 Group 父级里，避免 Group 删除子层后自动重算边界导致 PNG 漂移；只替换普通 Group 内的局部图层时，插件会把这个 Group 换成固定 Frame，再放入 PNG 和保留层，避免位置漂移和遮挡顺序变化。

## 注意

- 如果你勾选的是组、Frame 或实例，它内部全部内容都会打进 PNG。
- 如果你勾选的图层分散在不同父级下，一张 PNG 会放到它们的最低共同父级里。默认放在受影响层级的最底层位置，通常更适合保留文字在上方。
